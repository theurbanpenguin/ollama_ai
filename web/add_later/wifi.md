# Office Wi-Fi Support

## Staff network
Employees should connect company-managed laptops to the `UrbanStaff` wireless network. Sign in using the employee's company account. The guest network is intended for visitors and must not be used to access internal services.

## Troubleshooting
If Wi-Fi disconnects, switch Wi-Fi off and on, move closer to an access point and restart the laptop. If other colleagues are affected, report the location and approximate time to the IT service desk.

## Escalation
The service desk will ask for the laptop asset number, office location and time of the failure. Do not send passwords in a support ticket.
