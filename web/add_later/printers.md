# Office Printer Support

## Adding a printer
Staff should install office printers from the company-managed printer directory. The default printer for the Cambridge office is `CAM-PRINT-01`.

## Printing issues
If a print job is stuck, check the printer display, confirm it has paper and toner, and cancel any stalled job before trying again. If printing still fails, raise a support ticket quoting the printer name and error message.

## Confidential printing
Confidential documents must be released at the printer using the employee's access card. Do not leave confidential printouts in the output tray.
